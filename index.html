02 / YOUR FIRST SESSION

A clear place to start.

Try Kalynt alongside your current editor. Start with a small project and one useful task.

  1. 1

    Install and open a folder

    Download your platform's installer below. Launch Kalynt and select Open folder from the home screen.

  2. 2

    Choose local AI or a cloud key

    Open Settings → Models and keys. For local AI, download and load a model that fits your memory. For cloud AI, add your provider's API key.

    Start small, expect honestly.Small local models are useful for explanations and code chat. Larger models are better suited to editing and agent tasks. Reserve memory for your OS and project; model files require additional disk space.
  3. 3

    Ask something you can verify

    Choose your model in the agent panel. Start with a prompt like this, then check the answer against the code:

    Explain how this project starts. Point me to the entry file and the command to run it. Don't change any files.

03 / THE DETAILS

Good questions.

Is Kalynt really free and open source?+

Kalynt is licensed under AGPL-3.0. You can inspect the source, build it yourself, and contribute. There is no Kalynt subscription. External cloud AI providers may charge you for API usage.

Read the license ↗
Does my code leave my computer?+

With a local model, AI inference runs on your machine. If you choose a cloud model, the context needed for your request is sent directly to that provider. Collaboration shares workspace data with the peers you join. Model downloads, updates, and agent web searches also require network access.

What hardware do I need for local AI?+

It depends on the model and context size. The model manager shows estimated memory and download requirements before you download. Smaller models handle simpler tasks; larger coding agents need substantially more memory. Leave RAM for your operating system, IDE, and project. Supported GPUs can accelerate inference; CPU inference is available but can be slower.

Can I keep using my current editor?+

Yes. Kalynt opens ordinary project folders and uses your existing Git repository. Try a small task alongside your current tools. Extensions come from Open VSX or .vsix files; compatibility varies because Kalynt implements a subset of the VS Code API.

How do I get help or contribute?+

Report a reproducible issue on GitHub, ask a question in Discussions, or read the contribution guide. Include your Kalynt version, operating system, model or provider, and the steps you tried. Keep API keys and private code out of reports.
